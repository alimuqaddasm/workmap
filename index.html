Connect your GitHub key

This site holds no course data. It reads your progress from your private hub repo, with a key that stays in this browser only. Anyone else who opens this address sees this page and nothing more.

  1. On GitHub, open Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token.
  2. Repository access: Only select repositories, and pick hub.
  3. Repository permissions: Contents: Read and write. Nothing else.
  4. Generate it, copy it, and paste it here.
