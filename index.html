Connect your GitHub key

This site holds no course data. It reads your progress from your private repos hub-data and hub-notes with a key that stays in this browser. The key never needs the hub itself. Anyone else who opens this address sees only this page.

  1. On GitHub, open Settings, Developer settings, Personal access tokens, Fine-grained tokens, and generate a new token.
  2. Expiration: 90 days. Repository access: only select repositories, and pick hub-data and hub-notes.
  3. Repository permissions: Contents, read and write. Nothing else.
  4. Paste the token here.

The hub could not be read

Check your connection and that the key still has access to hub-data and hub-notes, then try again.
